# Signet

Signet issues school certificates with a cryptographic seal and verifies photos or scans of them fully offline. We don't accuse, we explain.

## Requirements

- Python 3.11 or 3.12
- No system binaries required

## Quick start

```bash
./run.sh          # macOS / Linux
run.bat           # Windows
```

Then open http://localhost:8000
